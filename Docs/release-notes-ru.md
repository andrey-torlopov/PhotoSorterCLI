# PhotoSorterCLI 1.0.0

- В заголовке меню отображается `v.1.0.0`; `--version` выводит `photos-sorter-cli 1.0.0` без открытия меню.
- Пункт **7 — Язык / Language** сразу переключает интерфейс: **1 — English**, **2 — Русский**, **0 — Назад**. Выбор действует до завершения запуска.
- Поддерживаются `--language` / `--lang`, определение локали, ответы «да/нет» и yes/no, все шесть операций с фотографиями.
- Конец ввода завершает диалоги без запуска неполной файловой операции. Неизвестные и конфликтующие аргументы завершаются с кодом 64.
- Удаление оригиналов по умолчанию выключено и требует явного ответа «да». Разделители формата даты сохраняются.
- Используется опубликованный PhotoSorterCore **0.0.2**. Установщик размещает только `/usr/local/bin/photos-sorter-cli` и не обрабатывает фотографии.

Пакет предназначен для Apple Silicon (arm64), deployment target macOS 15.0 и новее. Intel этим пакетом не поддерживается. Фактические сведения о подписи, нотарификации, проверках и проверенных системах указаны в опубликованном релизе. Документация исходников сама по себе не подтверждает подпись или публикацию пакета.

Перед установкой сохраните PKG и SHA256SUMS в одной папке и выполните `shasum -a 256 -c SHA256SUMS`. Откройте PKG штатным установщиком macOS, затем проверьте `photos-sorter-cli --version`. Сначала проверяйте обработку на копиях фотографий с выключенным удалением.
